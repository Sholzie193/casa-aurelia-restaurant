# Casa Aurelia

Multi-page luxury hospitality website concept for a fictional three Michelin star Italian restaurant in Florence.

## Pages

- `index.html` - home and site index
- `cuisine.html` - cuisine, service, and brigade story
- `menu.html` - tasting menu and dining notes
- `cellar.html` - wine cellar and pairings
- `visit.html` - private rooms and guest information
- `reservations.html` - reservation request form

## Local Preview

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Assets

Restaurant photography is stored in `assets/restaurant/`.
